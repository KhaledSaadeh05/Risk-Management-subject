## About the Project

Modern societies depend on **critical infrastructure** — systems such as power
grids, hospitals, telecommunication networks, and smart city services. Today
these systems are highly connected through the internet and IoT devices. This
connectivity makes them more efficient, but it also makes them an easy target
for cyberattacks.

**SHIELD-CI** is a study project that looks at the security of these systems.
It reviews **ten recent research papers** (all published after 2021) and uses
them to build a clear, organized picture of the cyber risks facing critical
infrastructure — and the ways to defend against them.

The project focuses on four main areas:

- **Critical infrastructure** (power, healthcare, telecom)
- **Smart cities**
- **IoT (Internet of Things) environments**
- **Cloud security**

---

## Objectives

The main goal is to understand how critical infrastructure can be protected
from evolving cyber threats. To do this, the project aims to:

1. **Classify the main threats** that target critical infrastructure.
2. **Classify the main vulnerabilities** (weaknesses) in these systems.
3. **Classify the main countermeasures** and security controls used to defend them.
4. **Map the relationship** between threats, vulnerabilities, and countermeasures.
5. Highlight the role of modern technologies such as **Artificial Intelligence**
   and **Big Data**, the importance of **training and awareness**, and the need
   for a **multi-layered ("defense-in-depth")** approach.

## Key Concepts (Quick Glossary)

If you are new to cybersecurity, these four terms are the heart of the project:

| Term | Simple Meaning |
|------|----------------|
| **Threat** | Something that could cause harm (e.g., a ransomware attack). |
| **Vulnerability** | A weak point that a threat can exploit (e.g., outdated software). |
| **Countermeasure** | An action or tool that prevents or reduces an attack (e.g., a firewall). |
| **Risk Assessment** | The process of finding threats and weaknesses and judging how serious they are. |
| **Risk Management** | Deciding which risks matter most and what to do about them first. |

In short: a **threat** uses a **vulnerability** to cause damage, and a
**countermeasure** stops it. **Risk management** is the process that ties all
of this together.

## What the Project Covers

The full project report is organized into the following parts:

- **Introduction** — the main security issues in critical infrastructure and
  why risk management matters.
- **Related Works** — short summaries of the 10 reviewed research papers.
- **Threats Table** — the main attack types found in the papers, with their
  place, description, and impact.
- **Vulnerabilities Table** — the main weaknesses that make these systems
  exposed to attack.
- **Countermeasures Table** — the security controls used to prevent, detect,
  or reduce attacks.
- **Mapping Table** — links each threat to a vulnerability and to a suitable
  countermeasure.
- **References** — the full list of the 10 sources.

---

## Methodology

The project followed a simple, step-by-step process:

1. **Select** ten research papers published after 2021 in the areas of
   critical infrastructure, smart cities, IoT, and cloud security.
2. **Read and summarize** each paper to understand its main ideas.
3. **Extract** the threats, vulnerabilities, and countermeasures mentioned in
   each paper.
4. **Classify** this information into clear tables.
5. **Map** the connections between threats, vulnerabilities, and countermeasures.
6. **Conclude** with practical, layered defense strategies.

## Papers Reviewed

The project is based on these ten sources:

1. **What is Infrastructure Security?** — HPE
   <https://www.hpe.com/emea_europe/en/what-is/infrastructure-security.html>
2. **Cybersecurity Risk Assessment in Smart City Infrastructures** — MDPI
   <https://www.mdpi.com/2075-1702/9/4/78>
3. **Data Governance to Counter Hybrid Threats against Critical Infrastructures** — MDPI
   <https://www.mdpi.com/2624-6511/7/4/72>
4. **Internet of Things Meet Internet of Threats: Cyber Security Issues of Critical Cyber Infrastructure** — MDPI
   <https://www.mdpi.com/2076-3417/11/10/4580>
5. **Security Risk Modeling in Smart Grid Critical Infrastructures in the Era of Big Data and AI** — MDPI
   <https://www.mdpi.com/2071-1050/13/6/3196>
6. **Predicting Cybersecurity Threats in Critical Infrastructure for Industry 4.0** — MDPI
   <https://www.mdpi.com/1424-8220/23/9/4539>

   <https://dione.lib.unipi.gr/xmlui/bitstream/handle/unipi/14572/Zampati_men20011.pdf>
